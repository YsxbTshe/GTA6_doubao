# GTA6_doubao

基于用户上传代码完善的原创 2D 城市驾驶原型，使用原生 JavaScript 和 Canvas 2D。游戏保留步行、上下车、驾驶、行人、通缉等级和昼夜变化。图形由 Canvas 绘制，无需下载图片或游戏素材。

## 本地运行

需要 Node.js 20.19+ 或 22.12+ 的受支持版本，以及 npm。

```sh
npm ci
npm run dev
```

访问终端显示的地址，默认是 http://localhost:3000。

## 检查与构建

```sh
npm run check
npm run build
npm run preview
```

构建结果位于 `dist/`，可以部署到静态网站托管服务。资源使用相对路径，支持部署到仓库名称对应的子目录。

## 操作

| 操作 | 键位 |
| --- | --- |
| 步行移动 | WASD 或方向键 |
| 驾驶加速、刹车与倒车 | W / S 或上 / 下方向键 |
| 驾驶转向 | A / D 或左 / 右方向键 |
| 上下车 | E，靠近车辆上车，减速停车后下车 |
| 暂停与继续 | P 或屏幕按钮 |

触摸设备提供方向键和上下车按钮。切换窗口或隐藏页面会自动暂停，点击“继续”返回游戏。出生点旁有一辆可立即驾驶的汽车。

高速撞击建筑、地图边界、车辆或撞到行人会增加通缉。连续 12 秒没有新的违规行为，通缉降低一级。速度沿用原型的相对数值。一个昼夜周期为 180 秒。

## 文件结构

- `index.html` 为页面入口，其前 10 行内容和 CRLF 换行与上传文件逐字节一致。`.gitattributes` 防止 Git 自动转换该文件换行。
- `src/game.js` 包含固定时间步长的游戏循环、碰撞、输入和 Canvas 绘制。
- `src/style.css` 包含界面、窗口适配和触屏按钮样式。
- `vite.config.js` 和 `package.json` 配置开发、构建和预览，`package-lock.json` 固定依赖版本。
